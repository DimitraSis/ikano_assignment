# Features

## Fibonacci

Calculates the Fibonacci number at a given position using an iterative approach.

Handles:

- n = 0
- n = 1
- invalid negative input

---

## Factorial

Calculates n!

Handles:

- 0! = 1
- invalid negative input
- values greater than 10 rejected

---

## Loan repayment

Calculates monthly loan repayment using:

M = P × [ r(1+r)^n / ((1+r)^n - 1) ]

Handles:

- zero and negative interest loans
- realistic month validation (up to 40 years)
- decimal-safe financial calculations
- proper rounding

---

# Data Persistence

Loan repayment calculations are automatically stored in a local SQLite database.

Stored fields:

- principal
- annual_rate
- months
- monthly_payment
- created_at (timestamp)

Database file:

```text
loan_calculations.db
```

# API Endpoints

## Fibonacci

```text
GET /fibonacci/{n}
```

Example:

```text
/fibonacci/10
```

---

## Factorial

```text
GET /factorial/{n}
```

Example:

```text
/factorial/5
```

---

## Loan repayment

```text
POST /loan_repayment
```

Example request body:

```json
{
  "principal": 1000,
  "annual_rate": 0,
  "months": 12
}
```

# Validation

The API validates:

- invalid negative inputs
- unrealistic loan durations
- unsupported factorial values
- malformed request bodies

Invalid requests return appropriate HTTP 400 responses.
